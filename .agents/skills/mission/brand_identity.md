# 品牌識別規範 (Brand Identity)

## 1. 品牌精神與由來
- **品牌名稱**：Frozen Rabbit (冷凍兔肉)
- **品牌故事**：本品牌源自開發者在 FFXIV 中的角色名稱「冷凍兔肉」。
- **品牌定位**：由懂遊戲的人為愛遊戲的人做的工具。它不是冷冰冰的資料表，而是把繁瑣準備工作整理好的實用工作台。
- **品牌目標**：讓玩家感受到「兔肉不私藏」的可靠與便利。

## 2. 品牌人格與語氣
- **友善**：用語親切、溫暖，避開過度生硬的技術語言。
- **方便**：強調快速上手、少走冤枉路、清單清楚。
- **可靠**：資料來源透明、錯誤狀態可理解、估算邊界不誇大。

## 3. Workshop 的視覺方向
- Workshop 側重能工巧匠與物資籌備，視覺應像乾淨、好用、資訊密度適中的工作台。
- 可延續 Frozen Rabbit 系列的 soft-green、冰晶與兔肉品牌元素。
- 大型清單與工具頁面應優先維持掃描效率，不要變成裝飾性 landing page。
- 圓角、陰影與微動畫可以使用，但應服務互動狀態與層級，不應喧賓奪主。

## 4. Agent 執行規範
- 撰寫 UI 文案、FAQ 或 README 時，使用「友善且專業的朋友」語氣。
- 涉及成本或時間時，誠實標示為估算。
- 若需調整 logo 或主要視覺資產，先確認品牌一致性與實際用途；不要只為了裝飾生成新圖。
