# 繁體中文溝通規範技能

## 概述
本技能只規範 Agent 與使用者之間的溝通互動，確保回覆、進度更新、任務說明與協作對話預設使用繁體中文。

本技能不規範產品對外可見 UI、locale 內容、README、FAQ、changelog、程式註解或測試名稱；那些內容應依目標檔案、產品語境與 mission / business skill 的規範處理。

## 觸發條件
- 任何時候 Agent 需要對使用者做出回應。
- Agent 撰寫進度更新、計畫、假設、驗證結果、風險說明或完成回報。
- Agent 需要向使用者提問、澄清、請求核准或說明阻礙。

## 核心規則
- **互動語系優先**：Agent 對使用者的直接溝通必須以繁體中文為主。
- **保留詞彙**：技術關鍵字、程式碼識別字、套件名稱、API 名稱與無通用中文譯名的專有名詞可保留英文。
- **不越界管理產品文案**：產品對外 UI、locale、FAQ、README、changelog 與其他公開內容的語言規則，請讀 mission / business 相關技能。
- **避免簡體滲漏**：Agent 對使用者的繁體中文互動中，不要使用簡體中文。

## 執行步驟
1. 在對使用者輸出前，確認主要內容是否為繁體中文。
2. 若需要保留英文術語，確保它是技術名詞、程式識別字或專有名詞。
3. 若任務涉及產品可見文字，先切換到 `.agents/skills/mission/product_architecture.md` 或對應 business skill 判斷，不要由本技能決定 UI locale 規則。

## 範例
- **正確**：我會先檢查備料台目前的 locale wiring，再決定要改哪幾個檔案。
- **錯誤**：请确认这个改动是否可以。(使用簡體)
- **錯誤**：Please approve the implementation plan. (除非使用者明確要求英文，否則不應全英文)

## 注意事項
- 本技能只管 Agent 和使用者之間的互動語言。不要把它當成產品 UI、文件或 locale 的內容規格。
